# 外贸09 · 产品规格确认（Product Specification）

> 场景：产品参数还没"钉死"，需要和客户书面确认
> 目标：把规格从口头变成书面 Spec Sheet，杜绝"我以为你说的是这个"

## 一、哪些规格必须书面确认（Checklist）

按产品类型选，常见项：

| 类别 | 参数项 | 确认方式 |
|---|---|---|
| 尺寸 | Dimensions 尺寸、Tolerance 公差（±0.1mm） | 图纸 2D/3D |
| 材料 | Material & grade（如 ABS / 304 stainless steel） | 材料规格书 |
| 外观 | Color、Finish（matte/glossy）、Texture | 色板/样板 |
| 性能 | Electrical/Mechanical specs、Rated power、Capacity | 测试报告 |
| 包装 | Inner/outer pack、Qty per carton、Carton size/weight | 包装规格 |
| 合规 | CE / RoHS / FCC / REACH certificates | 证书文件 |
| 标识 | Logo、Labeling、Marking（UL mark 等） | 标签样板 |

## 二、确认规格的三个动作

1. **发规格书请客户确认**：附图纸/参数表，写明"请回复确认或指出修改"。
2. **变更必须重发**：任何参数改动，重新发更新版 Spec，注明版本号（Rev. A / Rev. B）。
3. **封样**：样品确认后双方签字封样（sealed sample），作为量产验收基准。

## 三、英语高频表达

**发规格书：**
- Please find attached the **specification sheet** (Rev. A) for [产品].
- Please **review and confirm** the specifications, or let us know any changes.
- The tolerance for the outer dimension is **±0.1 mm**.

**客户提修改：**
- Could you change the housing material **from ABS to PC**?
- The logo should be **engraved instead of printed**.
- Please increase the **carton quantity** from 50 to 60 pcs.

**回应修改：**
- Noted. We have updated the spec to Rev. B. Please find it attached.
- This change will affect the **tooling** and add [X] days to the lead time.
- We can do that, but the **unit price may increase by** [X]% due to the material change.

## 四、规格确认邮件模板

```
Subject: Specification Confirmation — [产品/型号] Rev. A

Dear [Name],

Please find attached the specification sheet for [产品/型号] 
(Rev. A), including drawings, key parameters, and packaging details.

Key points for your review:
- Material: [材料]
- Dimensions: [尺寸] (tolerance ±[X] mm)
- Finish: [表面处理]
- Certifications: [CE / RoHS / ...]

Could you please review and confirm by [日期]? If there are any 
changes, just reply with your comments and we will issue Rev. B.

Once confirmed, we will proceed with [打样/模具/排产] accordingly.

Best regards,
[你的名字]
```

## 五、易错点

1. **"规格"**：**specification**（口语简称 spec / specs）。别说 "standard"（那是标准）。
2. **"公差"**：**tolerance**——±0.1 mm 读作 "plus or minus point one millimeter"。
3. **"确认"**：**confirm / approve**。confirm 是"确认无误"，approve 是"批准"，规格环节用 confirm 居多。
4. **"版本"**：**revision**（Rev. A / Rev. B），别写 version 也行但 Rev. 是行业惯例。
5. **"封样"**：**sealed sample / golden sample**——双方签字封存的验收基准。

## 六、小练习

1. 翻译：请审阅并确认规格书 Rev. A，如有任何修改请回复我们。
2. 客户说 "The tolerance of ±0.2mm is not acceptable. We need ±0.05mm."，你要考虑什么再回复？
3. 选词：The logo should be **embossed instead of / instead to** printed.
