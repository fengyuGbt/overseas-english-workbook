# 外贸07 · 订单生命周期总览（Order Lifecycle Map）

> 场景：外贸订单从询盘到量产的全流程地图
> 目标：知道自己在哪个阶段、下一步该说什么、向谁要什么

## 一、两条业务主线

外贸订单按"产品成熟度"分两条线，走的阶段不同：

**A. 制造线（成熟产品/贴牌 OEM）**——产品已定型，走确认流程：

```
报价 → 审厂 → 产品规格确认 → 工艺确认 → 质量标准确认
     → 客户许可生产 → 量产 → 验货 → 发货
```

**B. 开发线（新品/ODM 联合开发）**——产品未定型，先开发后生产：

```
报价 → 打样（数量/费用/付款）→ 规格确认 → 工艺确认 → 质量标准确认
     → 开发里程碑 → 客户许可生产 → 量产 → 验货 → 发货
```

## 二、阶段地图与核心动作

| 阶段 | 核心动作 | 关键英文动词 | 交付物 |
|---|---|---|---|
| 1. 审厂 | 客户/第三方来厂审核 | audit, inspect, walk through | Audit Report |
| 2. 规格确认 | 双方书面锁定参数 | confirm, approve, sign off | Spec Sheet |
| 3. 工艺确认 | 确认制造流程与工装 | validate, finalize, pilot run | Process Flow / FAI |
| 4. 质量确认 | 定验收标准与抽样 | define, agree on, inspect | QC Standard / AQL |
| 5. 打样（开发线） | 样品数量、费用、付款 | quote, charge, prepay | Samples + Sample Fee Invoice |
| 6. 进度管理 | 里程碑跟进与汇报 | track, report, update | Project Timeline |
| 7. 许可生产 | 客户正式批准量产 | approve, release, give the green light | Production Approval |
| 8. 量产交付 | 生产、验货、出货 | manufacture, inspect, ship | Goods / B/L |

## 三、两个核心原则

1. **每过一关，必有书面确认**：规格、工艺、质量、许可生产——每一项都要邮件/签字确认，口头"OK"不算数。**没有书面确认，就没有下一步**。
2. **每关都是英文沟通点**：审厂通知、规格确认邮件、FAI 报告、打样报价、进度周报、放行请求——每关都有一套固定话术（见 08-12 各课）。

## 四、阶段判断练习

判断以下场景属于哪个阶段、下一步要做什么：

1. 客户说 "We'd like to visit your factory next month." 
2. 客户说 "Can you make the housing in matte black instead of glossy?"
3. 客户说 "Please send us 5 samples with your quotation for the tooling."
4. 客户说 "We have reviewed the FAI report and approved the first article."
5. 客户说 "OK, you can start mass production now."

<details>
<summary>参考答案</summary>

1. 审厂阶段（Stage 1）——准备 audit agenda、安排接待、准备资质文件。
2. 规格确认（Stage 2）——书面更新 spec，请客户确认变更。
3. 打样（Stage 5）——确认样品数量、样品费/模具费、付款方式、运费承担。
4. 工艺/质量确认（Stage 3-4）——FAI 通过，可进入下一步（批量试产或等待许可生产）。
5. 许可生产（Stage 7）——拿到书面放行，排产、下内部工单。
