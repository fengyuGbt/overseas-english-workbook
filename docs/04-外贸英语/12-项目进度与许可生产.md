# 外贸12 · 项目进度与许可生产（Timeline & Production Approval）

> 场景：开发项目推进中——里程碑汇报、延期预警、最后"批准量产"
> 目标：进度沟通让客户放心，拿到书面"许可生产"再开干

## 一、项目进度管理（Project Timeline）

**标准的开发项目拆法（里程碑式）：**

| 里程碑 | 英文 | 产出 |
|---|---|---|
| 启动 | Kickoff | 项目计划、分工 |
| 打样完成 | Prototype / Sampling complete | 样品 |
| 规格确认 | Specification approved | 签字的 Spec |
| 试产 | Pilot run / Trial production | FAI 报告 |
| 许可生产 | Production approval | 放行单 |
| 量产交付 | Mass production & shipment | 大货 |

**进度汇报高频句（主动报，别等客户问）：**
- The project is **on track**; we are on schedule for [里程碑].
- We have **completed** the [阶段] and moved on to [下一阶段].
- The [环节] is **slightly behind schedule** due to [原因].
- We will **catch up** by [日期] and the final delivery will not be affected.
- Please find attached the **updated project timeline**.

**延期沟通（三个关键）：**
1. 第一时间说（don't wait until the deadline）
2. 给原因 + 给新日期（reason + new date）
3. 给出补救措施（mitigation：加班/加人/分批交付）

## 二、许可生产（Production Approval）——最重要的一关

**客户会说的话：**
- We have **approved** the FAI report. You can proceed.
- The product is **approved for production**. Please start mass production.
- You have our **green light** to start the bulk order.

**你要主动要的书面确认（如果客户只说"OK"）：**
- Could you please **confirm in writing** that we can proceed to mass production?
- We would like your **formal approval** before we start production.
- Once we receive your **production approval**, we will arrange the production schedule.

## 三、进度汇报邮件模板（周报）

```
Subject: Project Update — [项目名] (Week [X])

Dear [Name],

Here is the weekly update for [项目名]:

- Progress: 
  ✅ [已完成事项，如 tooling completed]
  🔄 In progress: [进行中事项]
  ⏳ Next: [下一步]

- Status: On track / Slightly delayed
  [若延迟] The [环节] was delayed due to [原因]. We have 
  adjusted the schedule; the milestone will be completed by [新日期].

- Action needed from you: [需要客户配合的事，如 confirm spec / 
  approve sample / arrange inspection]

Next update: [日期]

Best regards,
[你的名字]
```

## 四、请求生产放行邮件模板

```
Subject: Request for Production Approval — [产品/型号]

Dear [Name],

Following the successful pilot run and FAI report approval, 
all specifications and quality standards have been confirmed.

We would like to request your **formal approval to proceed 
with mass production** of [数量] units, according to the 
confirmed spec (Rev. B) and quality plan.

The planned production schedule is:
- Production start: [日期]
- Estimated completion: [日期]
- Shipment: [日期]

Please reply with your confirmation so we can start on time.

Best regards,
[你的名字]
```

## 五、易错点

1. **"按计划/落后/超前"**：**on track / behind schedule / ahead of schedule**。
2. **"放行"**：**production approval / release to production / give the green light**。正式点用 approval。
3. **"赶上进度"**：**catch up**（We will catch up by...）；"进度表" = **timeline / schedule**。
4. **"里程碑"**：**milestone**（不说 stage 也行，但 milestone 是项目管理的标准词）。
5. **"书面确认"**：**in writing / written confirmation**——口头 OK 不算数，这一步最重要。

## 六、小练习

1. 翻译：试产和首件检验已经通过，请正式批准我们开始量产。
2. 客户说 "OK, go ahead."，但你想要书面确认，怎么回？（写 2 句）
3. 选词：The project is slightly **behind / late** schedule.
