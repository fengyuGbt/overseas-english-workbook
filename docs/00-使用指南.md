# 00 · 使用指南

## 适合谁

- 准备接海外业务（Fiverr / Upwork / 直客）的独立开发者
- 已能读写基础英文技术内容，但听说跟不上、写邮件不放心的人
- 目标：**能独立完成从接需求 → 报价 → 沟通 → 交付 → 收款的全流程英文沟通**

## 怎么用这本书

### 听力章节（02-听力训练）

每课固定流程：

1. 点开课程文件中的音频（`audio/01.mp3`…`audio/06.mp3`，GitHub 上可在线播放），**不看脚本**先听 1 遍，抓大意
2. 再听 2-3 遍，**逐句听写**，写不出的地方留空
3. 对照"原文脚本"批改自己的听写稿
4. 看"本课批改要点"——标注了这类场景最容易错在哪
5. **跟读**：把错过的句子跟读 3 遍（听力输入 → 口语输出）

### 邮件章节（03-商务邮件）

1. 先看"场景任务"，**自己先写**，不要看范文
2. 对照"逐句批改"和"标准范文"自查
3. 把"本课必记"的词块各造一个句子，写进自己的词库

### 错因归档

每轮错误分七类，错一次记一类，连续错同类 = 顽固点，需要造句输出强制修正：

| 类别 | 含义 |
|---|---|
| 弱读连读塌陷 | 整句/短语听崩（the scope I sent → skill by sand） |
| 单点音近误听 | 个别词音素错误（paid tier → paid year） |
| 数字误听 | teen/ty 等数字陷阱（fifty → fifteen） |
| 词汇未激活 | 阅读认识但听不出（recurring revenue → current revenue） |
| 语法搭配 | 固定搭配/语法错误（look forward to + doing） |
| 专名听辨 | 人名、公司名（QuantEdge → quantask） |
| 拼写 | 拼错（upfront → unfront） |

## 训练节奏建议

- 听力阶段：每天 10-15 分钟精听
- 邮件阶段：每周 2 封邮件 + 1 次口语角色扮演
- 每个错词：造一个自己的句子（不是抄例句）
