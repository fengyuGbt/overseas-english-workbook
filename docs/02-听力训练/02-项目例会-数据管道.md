# 听力02 · 项目例会（数据管道）

> 场景：项目例会 standup（英音，约 1 分钟）｜主题：市场数据管道进度同步
> 音频：https://aka.doubaocdn.com/s/YnipnX0K4w

## 原文脚本

```
Morning everyone, quick update on the market data pipeline. The
integration with the options data feed is now about eighty five percent
complete. We resolved the timeout issue in the batch job yesterday, so
the sandbox environment is stable. On the financial side, the pricing
model is finalized: we will charge a flat rate of two point nine percent
plus thirty cents per successful transaction for the paid tier. The
finance team confirmed the margin is around forty percent after data
costs. Next steps: QA starts Monday, and we are still targeting
production launch on the twenty eighth. If you have questions about the
fee structure, talk to Lisa in Finance.
```

## 本课批改要点

- **错数**：13 处
- **数字全部抓对**：85%、2.9%、30 美分、40%、28 号——数字专项初见成效
- **翻案项**：timeout issue（听力01 时听成 bank deposit）这次全对
- **经典误听**：flat rate → "flight rate"、paid tier → "paid year"、QA starts → "QA stops"（意思相反）

## 本课必记

1. **例会开场**：quick update **on** the ...
2. **费率结构**：a flat rate of 2.9% **plus** 30 cents per transaction / the **paid tier**
3. **QA 开始了**：QA **starts** Monday（start 别听成 stop——意思完全相反）
4. **里程碑动词**：resolved the timeout issue / targeting production launch **on the 28th**
