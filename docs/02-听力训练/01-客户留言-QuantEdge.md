# 听力01 · 客户留言（QuantEdge Analytics）

> 场景：客户留言（美音，约 1 分钟）｜角色：Daniel Park，QuantEdge Analytics
> 主题：询盘——可用性 + 粗略报价 + 英文文档 + 视频通话
> 音频：audio/01.mp3（仓库内文件，可在线播放）

## 原文脚本

```
Hi, this is Daniel Park from QuantEdge Analytics. I found your profile
on the freelancing platform, and I'm impressed with your work on market
microstructure and the crash simulator. We're looking for a developer
to build an automated pipeline that pulls options data, computes dealer
gamma, and generates a daily report. The project would start in about
two weeks. Before we move forward, could you send me your availability
for the next month and a rough quote based on the scope I sent? Also,
we need the code documented in English, because our team is spread
across three time zones. If everything looks good, we would like to
schedule a video call next week. My email is in the project description.
Thanks, and I look forward to hearing from you.
```

## 本课批改要点

- **错数**：16 处
- **最大类**：弱读连读塌陷 5 处——based on the scope I sent → "skill by sand"、spread across → "explash"
- **专名听辨**：QuantEdge Analytics → "quantask analysitics"、market microstructure → "marcostructure"

## 本课必记

1. **专名首听必问拼写**：公司名/人名第一次出现没听清，当场问 "Could you spell that, please?"
2. **look forward to + 动名词**：look forward **to hearing** from you（不是 hear）
3. **基于……的报价**：a rough quote **based on the scope I sent**
4. **跨时区协作**：spread **across** three time zones（介词是 across 不是 in）
