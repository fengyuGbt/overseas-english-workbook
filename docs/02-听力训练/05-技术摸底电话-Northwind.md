# 听力05 · 技术摸底电话（Northwind Labs）

> 场景：技术摸底 discovery call（美音）｜角色：Sarah，Northwind Labs
> 主题：Python + AWS 数据管道、ETL、时区重叠、NDA/SOW
> 音频：https://aka.doubaocdn.com/s/rbtgaxsX2m

## 原文脚本

```
Hi, thanks for taking the call. I am Sarah from Northwind Labs.
Actually, this is a technical discovery call, so I will keep it short.
We saw your portfolio, and the crash simulator really stood out. We
have a data pipeline project that needs someone who knows Python and
AWS. The stack is Python, Postgres, and S3, and we run everything on
EC2. Your main task would be to build an ETL job that pulls tick data
from our exchange feed, cleans it, and loads it into a warehouse. We
also need basic monitoring, alerts when the pipeline fails, or when
latency goes above five minutes. For the contract, we are thinking a
three-month engagement, around forty hours a week, and we can offer
sixty-five dollars an hour. You would work with our team in New York,
so we need at least four hours of overlap with Eastern time. If that
sounds good, we will send the NDA and the SOW by the end of the week.
Do you have any questions about the stack?
```

## 本课批改要点

- **错数**：30 处（技术词密度跳档，**不是退步**，是难度跳档）
- **数字全对**：40 小时/周、65 美元/时、5 分钟、4 小时重叠
- **新瓶颈 = 技术缩写**：AWS/S3/NDA/SOW 听出音写不出字母
- **技术词**：Postgres → "push scratch"、EC2 → "azture"、latency → "leitecy"

## 本课必记

1. **缩写听字母**：AWS（A-W-S）、EC2（E-C-two）、S3（S-three）、NDA、SOW——听到不认识的缩写当场问拼写
2. **必须耳熟的技术词**：Postgres、tick data（逐笔行情）、exchange feed、latency、overlap（时段重叠）、stack（技术栈）
3. **语义陷阱**：**pulls**（拉取）≠ push（推送），pipeline 语境听反是事故
4. **数字+名词作定语不加 s**：three-**month** engagement、sixty-five dollars **an hour**
