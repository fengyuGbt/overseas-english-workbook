## 六轮进步点

1. **数字抓取**：01 只抓到 40% → 02 全对 → 03 错 2 处 teen/ty → 04 全对 → 05 全对 → 06 的 8 个数字 7 个对，唯一错点 fifty thousand→15 thousand
2. **翻案项**：timeout issue（01 听成 bank deposit，02 全对）；Northwind（05 听成 noise relapse，06 全对）；teen/ty 六轮中四轮通过
3. **结构改善**：词汇未激活 4→2、专名听辨 5→1——05 的技术词训练直接见效（GitHub/Jira/pull request/merge/push 全对）
4. **新暴露**：due in→doing、deployment→development 等词义级错误——从"听不出音"进阶到"听得出音但词义混淆"
