## 缩写听字母

听到不认识的缩写，**当场问拼写**："Could you spell that, please?" 或 "What does that stand for?"

| 缩写 | 读法 | 含义 |
|---|---|---|
| AWS | A-W-S | 亚马逊云 |
| EC2 | E-C-two | 弹性计算实例 |
| S3 | S-three | 对象存储 |
| ETL | E-T-L | 抽取-转换-加载 |
| NDA | N-D-A | 保密协议 |
| SOW | S-O-W | 工作说明书 |
| QA | Q-A | 质量保障 |

## 语义陷阱

- **pulls**（拉取）≠ push（推送）——pipeline 语境听反是事故
- **deployment**（部署）≠ development（开发）
- **due in**（到期）≠ doing
- **access**（访问权限）≠ interview（面试）——"数据访问"是 access to the data

## 数字+名词作定语不加 s

- three-**month** engagement（三个月合同）
- six-**week** timeline（六周时间线）
- ten-**dollar** fee（十美元费用）
- 注意对比：in four **weeks**（作时间状语时 weeks 有 s）
