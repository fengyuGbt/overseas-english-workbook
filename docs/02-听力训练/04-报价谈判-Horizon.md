# 听力04 · 报价谈判（Horizon Data）

> 场景：客户电话谈价（美音）｜角色：Mark，Horizon Data
> 主题：砍价 9000→7500 + 50% 预付、4 周第一里程碑、每周英文进度报告
> 音频：audio/04.mp3（仓库内文件，可在线播放）

## 原文脚本

```
Hi, this is Mark from Horizon Data. We got your quote for the market
data pipeline, and overall, we are happy with the technical approach.
But before we move forward, we need to talk about two things. First,
the price: your quote is nine thousand dollars, which is above our
budget of seven thousand. Could you come down to seventy-five hundred,
that is seven point five K, if we pay fifty percent upfront? Second,
the timeline: you said six weeks, but we need the first milestone, the
data ingestion module, in four weeks, so we can demo it at our board
meeting. If we agree on these, we can sign the contract by Friday and
start next Monday. Also, we would like weekly progress reports in
English, since our investors are based in London. Let me know what you
think by Wednesday.
```

## 本课批改要点

- **错数**：14 处
- **9 个数字/日期全对**：9000/7000/7500/7.5K/50%/6/4/Friday/Monday——teen 陷阱首测通过（six weeks 没听成 sixteen）
- **谈判词块未激活**：upfront → "of freche"、come down to → "cutdown to"、weekly progress reports → "weak progress support"、investors based in → "xx are based on"

## 本课必记

1. **预付**：pay 50% **upfront**（写作常拼错 unfront，见邮件课）
2. **降到**：come **down to** $7,500（还价场景高频）
3. **里程碑**：the first milestone / the data ingestion module
4. **进度报告**：weekly **progress reports**
5. **投资人所在地**：investors are **based in** London（based in + 地点）
