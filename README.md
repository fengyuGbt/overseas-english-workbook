# 海外接单英语训练手册

> Overseas Contract English Workbook
> 给独立开发者 / 自由职业者的英语实战训练手册——接海外业务的听说读写全覆盖。

## 这本书是什么

不是背单词书，是一套**从真实接单场景里长出来的训练闭环**。所有材料都取材于海外业务中的真实场景：客户留言、项目例会、财报电话会、报价谈判、技术摸底电话、项目启动会。

覆盖 **4 技能 × 3 领域**：

| | 商务 | 编程 | 金融 |
|---|---|---|---|
| 听力 | 客户电话、谈判 | 技术摸底、例会 | 财报电话会 |
| 口语 | 会议发言、谈判 | 技术讨论 | 术语表达 |
| 读写 | 邮件、合同 | PR、文档 | 报告、指标 |

## 训练方法（闭环）

1. **听写精听**：听音频 → 写全文 → 逐句对照批改
2. **邮件实战**：写邮件 → 逐段批改 → 对照标准范文
3. **错因归档**：每轮错误分类归档，错一次抓一类
4. **跟读输出**：错过的词块造句输出，从"听懂"到"写对"
